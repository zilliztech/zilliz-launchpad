# Zilliz Launchpad

A spec-driven project powered by [OpenSpec](https://github.com/openspec-dev/openspec) for managing specifications and artifacts.

## Project Structure

```
openspec/
  config.yaml    # OpenSpec configuration
  specs/         # Specification files
  changes/       # Change tracking
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/zilliz/zilliz-launchpad.git
   cd zilliz-launchpad
   ```

2. Review and update `openspec/config.yaml` with your project context and rules.

3. Add your specifications under `openspec/specs/`.
